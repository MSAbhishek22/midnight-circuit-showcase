Midnight Circuit — a Hyper Elements kit —

One theme and one data file, dressed for a 24-hour hackathon in Bengaluru — rendered four ways, without a single line of duplicated layout.

Vol. 04 · 11–12 December 2026 · Bengaluru · 300 hackers · ₹4,00,000 in prizes

How the kit works

Three moving parts. Everything else is rendering.

Part 01

One theme

noirMarquee is defined once — near-black ground, bone text, one amber accent, one crimson reserved for the moment that matters. A print variant flips the same brand onto bone paper for the ticket.

Part 02

One data file

Every fact — name, schedule, three prize tracks, three judges, the ticket — lives in src/event.ts. Edit that one file and the email, page, ticket and card all re-issue themselves.

Part 03

Four outputs

The same shared components render an invitation email, a web page, a PDF e-ticket and a social card. The email is checked in Outlook, Gmail and Apple Mail; the skyline hero is drawn in code, not photographed.
